# CompChemWorld 的 Agent 能力维度试标

初始八维参考了 AutoMat 的六类复现失败表现，按计算化学中可定位的决策重新划分。AutoMat 对 73 次运行的专家复核中，多标签集合完全一致率为 47.9%。这次试标记录逐案分歧及判定依据，便于后来者核对每个标签的适用边界。[AutoMat 失败分类与标签审查](https://arxiv.org/html/2605.00803v2#A8.SS2)

这次试标用于划分能力维度。后续全量验收覆盖两批 196 个试次，并复核了自检脚本实际运行的证据。[全量验收结果](compchemworld-validation.md)

## 样本与判定标准

取 CompChemWorld `local-a` 和 `local-b` 的 15 个已保存 Harbor 试次。首轮取 13 个边界样本，其中八个用于独立对照（009、039、136、143、146、150、162、171）。定向补查后加入 093、099，覆盖回放状态传递和物理模型选择。每个试次只标表中指明的一个动作或拒绝，其他现象用于辨别边界。样本是有意选取的，表中频数仅描述本次试标。

**支持**要求有可定位的 Agent 动作、适用的要求或科学依据、实际提交或执行结果，以及三者之间的关联。**候选**要求已有具体 Agent 动作和可检验的假设，但仍缺契约、执行或因果区分证据。**弃标**适用于该事件已有外部解释，或现有记录无法定位 Agent 偏差。每个动作至多一个主维度，竞争解释仅留在备注。表内等级是基于源材料的试标判断，CFA 命令行审查另外要求满足证据绑定与指纹等门槛。试标限于该动作及其可证实的局部后果，沿用原始评测结果。材料来自〔公开任务与本地试次〕、〔local-b 重分析〕和〔既有复核〕，本轮只读源材料，未运行验证器或科学计算。

〔公开任务与本地试次〕指相邻的 `CompChemWorld-publish` 单独检出，版本 `fbe6f79e60de0920c588bf1fc811c139006c0fc9`。下表的试次路径位于该检出的 `jobs/comp-chem-world-local-a` 或 `jobs/comp-chem-world-local-b`，任务路径为 `tasks/<三位编号>-task<三位编号>/`。`step` 为 `agent/trajectory.json` 的 `step_id`。本地运行和审计文件随各自工作区保留。〔local-b 重分析〕见 审计清单（本地 `.dev/local-b-reanalysis/audit-results.json`），〔既有复核〕见 task136（本地 `.dev/local-b-reviewed/1794927255813997000/task136/review.json`） 与 task162（本地 `.dev/local-b-reviewed/1794927255813997000/task162/review.json`）。

## 定向补查

筛查范围为两批各 98 个原始试次的 `result.json`、43 份 `local-a` 与 66 份 `local-b` 已存 `analysis.json`，并以对应任务题目、根因代码和具名失败项定位几何建模、收敛与采样、执行恢复的线索。对 008、040、060、076、090–094、099、155、157、167、170 的公开要求、日志、轨迹或产物继续查证。其中 093、099 纳入上表，其他作为下述排除证据。未逐条复核所有运行轨迹。

- **D2**：040 审计既有固定几何的刚性平移和环境，保存的验证只指向 `static_path_checks` 对比，未把误差绑定到 Agent 构建体系的动作。157 保存的是既有石英 slab 审计键匹配失败。167 确实要求构建 W₂N₃，实际试次因输出限制停止，采集缺少可绑定的终态结构。170 是静态 QE 链设计，已有对称性配置 `nosym=.false.` 仍触发字面检查，不能由该失败推导物理模型错误。099 保留候选。
- **D3**：008 的交付脚本用解析区间覆盖实轴，保存的区间拒绝未定位到网格精度。060 的 AMSET 可信运行已经完成，保存的拒绝是结构化解释不完整。076 保存的失败集中在辅基比较使用的分子行标签。094 按规定固定块和种子产生 2,000 个重复样本，`analyze.py` 521–537 在每个重抽样曲线上沿用全样本 SE；`tests/_support/reference.py` 128–137 对每轮重算 SE，拒绝是低 k 谷的有效重复次数不同。现有公开文字未明确这一步的 SE 更新口径，采样充分性本身也未被证伪。
- **D5**：090 的轨迹 37–45 显示 Python 检查失败后修正积分节点并重新通过积分对照；最终拒绝涉及 `solver.log` 解析。091、155、167 的终止分别涉及输出上限或上下文压缩循环，仍缺 Agent 可控故障与失效处置的因果绑定。092 在新网格回放时拒绝缺少固定 `h8_public` 键，属于入口对输入契约的解释。093 有软件已执行并产出曲线的证据，失败定位于交付路径（D4）。

## 八维覆盖与修订建议

| 维度 | 支持 | 候选 | 试标边界 |
|---|---:|---:|---|
| D1 科学问题与物理量定义 | 1 | 0 | 先确认目标量、符号、单位或参考态的定义。task143 的提前停止与力范数定义是同一条因果链。 |
| D2 体系构建与物理建模 | 0 | 1 | 保留给组成、结构、边界条件、相互作用、模型和施加的物理近似。099 能定位物理模型替换，公开依据的可用性仍待查。 |
| D3 数值收敛与采样充分性 | 0 | 0 | 要有针对同一目标量的收敛准则、数值控制或采样设计偏差。终态未收敛、固定输入中已存在的病态参数以及统计口径争议均不足以单独支持。 |
| D4 工作流编排与状态传递 | 1 | 0 | 需确认依赖哪个输入、由哪一步生成，以及消费端运行时该产物所处的目录和状态。093 的路径要求明示，146 的回放再生成要求仍有歧义。 |
| D5 软件执行与故障恢复 | 0 | 0 | 先绑定 Agent 操作的软件进程及错误后的处置。需要增加 Agent 可控且确实未恢复的执行故障样本。 |
| D6 后处理与结果溯源 | 2 | 0 | 在已确定的物理量进入提取、派生、映射或引用之后，定位其与实际来源失配的步骤。 |
| D7 独立验证与自检 | 1 | 0 | 以自检的独立动作、覆盖范围及输出为证。当前仅有契约覆盖实例，科学量的独立交叉验证仍需单独样本。 |
| D8 科学结论与不确定性判断 | 1 | 1 | 涵盖由数据得出科学判断时的可识别性、适用范围、统计可行域和不确定性。对固定输入中网格是否充足的科学判断与自行选取网格分属于不同动作。 |

15 个事件中，6 个支持、2 个候选、7 个弃标。三个边界关系反复出现。① 定义 D1 与计算/停机后果 D3 或写出 D6 的边界可在 143、039、010 的源码中观察。② 交付流程 D4、生成或溯源 D6 和检查 D7 的边界出现在 093、146、054、044，要求能标出入口、生成语句或自检命令。③ 009 和 171 都涉及数值或模型参数，但绑定的动作是评估现有证据能支持什么。另有两个验证器解析反例（136、162）与三个运行外因或未定位例（139、150、189）。这些是本轮观察到的混淆来源，频数来自上表逐条计数。

本轮建议保留八维作为候选词表。为每次标注保存观测动作、一个主维度、证据等级、竞争解释和判定范围，另外记录外部根因以及同一动作的下游后果。D2、D3 和 D5 仍缺能支持偏差归因的试例，D7 还需要科学量的独立交叉验证样本。后续可预先纳入这些边界的正例与反例，冻结同一批证据供领域审查者盲标，分别比较维度和证据等级并公开逐例分歧。

命令行验收只覆盖 009、039。009 的 `review plan` / `review apply` 输出为 `evidence_supported_cause`，同一试次的维度诊断为 `supported_in_trial`。039 的原始轨迹有 3,079,253 字节，超过 1 MiB 的单源指纹核验限额，输出为 `candidate_cause`，维度诊断是 `candidate`。这两个命令行结果只对应本地工区中的源材料和规则，试标未据此确认跨任务能力缺口。 009 验收（本地 `.dev/agent-capability-pilot/task009/analysis.json`） · 039 验收（本地 `.dev/agent-capability-pilot/task039/analysis.json`）
